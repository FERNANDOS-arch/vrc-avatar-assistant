# VRC Avatar Assistant — v1.2-alpha

Помощник Codex для настройки аватаров VRChat в Unity: одежда, предметы, меню, материалы, поиск плагинов и исправление ошибок. Агент сам определяет задачу и действует в пределах поручения.

## Что нужно для работы
| Что | Для чего | Ссылка |
| --- | --- | --- |
| Unity 2022.3.22f1 | Редактор аватара; версию сверяйте с VRChat | [Версия и установка](https://creators.vrchat.com/sdk/upgrade/current-unity-version/) |
| VRChat Creator Companion (VCC) | Проект Avatars и VRChat SDK | [Скачать](https://vrchat.com/home/download) |
| Codex с доступом к проекту | Выполнение поручений | Подключите используемый Codex к папке проекта |
| Unity-мост | Связь Codex с редактором | [Настройка](AI%20Assistant/START_HERE_RU.md) |

## Установка
1. Через VCC создайте проект Avatars или добавьте существующий. Сохраните копию проекта.
2. [Скачайте текущий комплект](VRC_Avatar_Assistant_v1.2-alpha.zip) и поместите AI Assistant рядом с Assets, Packages, ProjectSettings.
3. Откройте Unity, подключите Codex и Unity-мост.
4. Напишите: «Найди AI Assistant/AGENTS.md, прочитай его и выполни FIRST_RUN.txt. Аватар не изменяй».
5. Откройте Tools > VRC Avatar Assistant > Open.

Модуль копируется в Packages/com.vrc-avatar-assistant.editor доступными файловыми средствами. Дополнительная программа для запуска не требуется. [Подробности установки, копий и обновления](AI%20Assistant/MODULE_GUIDE_RU.md).

## Экономный процесс
Короткие основные правила, предпочтения и сводка проекта загружаются при начале сеанса. Остальные документы, память и история — только по необходимости. Агент сам выбирает операции, объекты и проверки, без выбора категории пользователем. Полные ответы инструментов и старые записи по умолчанию не загружаются. Процент экономии зависит от задач и пока не измерен.
