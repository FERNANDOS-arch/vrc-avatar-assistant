## Установка

Для установки модуля и работы с копиями файлов нужен Python 3.9 или новее: [скачать с официального сайта](https://www.python.org/downloads/). На Windows при установке включите «Add python.exe to PATH», если этот пункт доступен.

Скопируйте папку `AI Assistant` в корень проекта Unity. Перед обновлением сохраните существующие записи памяти, журналы и настройки пользователя.

В Codex задайте команду:

> Найди агента в папке AI Assistant в корне этого проекта, прочитай AI Assistant/AGENTS.md и связанные инструкции, затем выполни FIRST_RUN.txt.

## Основные правила

Агент выполняет необходимые действия в пределах текущего поручения. Улучшения за пределами поручения предлагает пользователю. Сначала применяет проверенные решения с подходящими версиями инструментов; затем действует по алгоритму диагностики.

Служебные файлы находятся в `AI Assistant`. Нужные аватару рабочие ассеты остаются в штатных папках Unity. Знания и алгоритмы находятся в `AI Assistant/AI Memory`; журналы конкретного проекта хранятся отдельно.

Облачная синхронизация памяти не включена. Результаты проверки файлов приведены в отчёте.

## Расширение Editor 1.2.0-alpha.1

- Общая локальная история ручных и ИИ-изменений с честной отметкой unknown.
- Автоматическая установка при FIRST_RUN, проверка запуска и повторная установка без перезаписи.
- Контрольные точки saved-файлов и восстановление с проверкой конфликтов.
- Проверки по типу задачи и отдельные критерии SDK/платформы.
- Сверка состояния перед шагом ИИ, пауза/STOP и восстановление контекста после reload.
- Окно Tools > VRC Avatar Assistant > Open.
- Профиль окружения, версии, целевой аватар и ограничения.
- Карточки решений с доказательствами и способом восстановления.
- Инвентарь зависимостей пакетов с сохраняемыми аннотациями.
- Обновление инструкций и пакета с сохранением истории, памяти и предпочтений.
