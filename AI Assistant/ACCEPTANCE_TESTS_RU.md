# Проверка процесса v1.2-alpha

1. Первоначальная установка: пустой пакет, повторный запуск, конфликт manifest, чужой пакет, локальные изменения, отсутствие файловых средств. Аватар не меняется при FIRST_RUN.
2. Короткий старт: AGENTS, USER_PREFERENCES, CURRENT_STATE; неизменённые данные повторно не загружаются. Отсутствующая сводка восстанавливается из нужных записей.
3. Произвольная задача: агент сам определяет объекты/операцию; категория не запрашивается. Неоднозначная цель уточняется.
4. История: несколько событий, Recent(5), расширение при конфликте; unknown не превращается в user без основания.
5. Копии: .meta, новый файл, повреждённая копия, более новая правка, preview, спасательная копия, восстановление при закрытом редакторе по MODULE_GUIDE.
6. Обновление: память, Solutions, знания, предпочтения и история сохраняются; локальные изменения пакета блокируют замену.
7. СТОП и reload: новые записи прекращаются; текущая задача и фактическое состояние сверяются перед продолжением.
8. Экономия: сравнить одинаковую задачу и объём прочитанного текста до/после; не заявлять неподтверждённый процент.
