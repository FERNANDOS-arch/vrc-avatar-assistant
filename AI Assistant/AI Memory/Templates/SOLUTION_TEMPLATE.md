## Переносимость

Использовать относительные к роли объекта обозначения и переменные вроде
<AVATAR_ROOT>, <ASSET_PATH>, <PROJECT_ROOT>; это placeholders, не исполняемые
пути. Перед применением разрешить их по текущему проекту. Не включать абсолютные
пути, Blueprint ID, активные разрешения, секреты, платные assets и project GUID.
Публичный package ID, error code и версия сохраняются. Локальные доказательства
хранятся в Reports проекта; карточка содержит сводку теста и его ограничения.
