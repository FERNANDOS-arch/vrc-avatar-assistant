# Модуль и работа с файлами — v1.2-alpha

## Установка без дополнительных программ
Codex использует доступные файловые средства ОС. Для установки пользователь вручную может выполнить те же действия.
1. Сверить корень: Assets, Packages, ProjectSettings; проверить manifest.json на существующую ссылку com.vrc-avatar-assistant.editor.
2. Источник: AI Assistant/Installer/package~. Назначение: Packages/com.vrc-avatar-assistant.editor. Проверить name в package.json. Если назначение занято чужим пакетом или manifest указывает другую поставку — остановиться и объяснить конфликт.
3. Если пакет уже установлен, сравнить файлы с сохранённым installation-record.json (пути/хэши). Совпадение не требует повторной установки. Локальные изменения не перезаписывать; при отсутствии записи не считать пакет принадлежащим помощнику автоматически.
4. Копировать во временную папку внутри проекта, исключив переходы через ссылки и пути вне проекта. Проверить размеры/хэши всех скопированных файлов. Новую поставку поместить в назначение; записать AI Assistant/History/installation-record.json с версией и хэшами. Не редактировать manifest/lock ради embedded-пакета.
5. Дождаться импорта Unity; прочитать VrcAvatarAssistant.AssistantHistory.Version, вызвать SaveProfile(), Record("health-check", "editor", "installed", "ai"), Flush(), Recent(5). Проверить событие в History/events.jsonl. Не выдавать наличие файлов за успешный запуск.

## API для агента
BeginTask(taskId, avatar, constraints): выбрать точный GameObject и зафиксировать задачу.
WatchDependencies(objects): зарегистрировать общие зависимости до первой правки.
RunAgentStep(action, affected): синхронный изменяющий вызов со сверкой состояния. Асинхронные действия требуют дополнительной сверки.
Stop(): запрет следующего шага; уже выполняющийся код может завершиться.
EndTask(result): закончить задачу. После reload сверять цель/состояние заново.
Recent(5), Status, Conflict, Revision: короткий текущий контекст.
Check(target, operation, expectedChild, expectedComponent): выбрать operation самостоятельно (general/clothing/prop/menu/materials), не спрашивать категорию у пользователя. Результат PARTIAL/FAILED требует интерпретации по задаче.
Автор событий без явной маркировки unknown. Полный перехват и техническая изоляция произвольного кода не гарантируются.

## Копии файлов перед изменениями
Это алгоритм для Codex, а не отдельная программа автоматического восстановления.
- Точный список saved-файлов в Assets/Packages/ProjectSettings, относящихся к задаче, и их .meta; новые пути записать как отсутствовавшие. Не допускать ссылок/выхода за проект.
- Создать уникальную папку AI Assistant/Backups/Checkpoints/<ID>; сохранить исходные байты и JSON-описание: относительный путь, существование до правки, SHA-256 до правки, путь копии. Проверить копии по SHA-256 до изменения оригиналов.
- После порученного сохранения записать SHA-256 результата/отсутствие каждого файла. Не перезаписывать эту запись повторно ради обхода конфликта.
- Восстановление: сначала показать точный план. Выполнять при закрытом Unity, только в рамках поручения на возврат. Проверить весь список до любой записи: текущие хэши должны совпасть с записанным результатом, копии — с исходными хэшами. Любое несовпадение блокирует восстановление всего списка.
- Сначала создать проверенную спасательную копию текущего состояния. Восстанавливать через временные файлы и замену; удалять только файлы, которых до задачи не было. Сохранить .meta. Несохранённые сцены не входят в копию. Многофайловая операция не является одной неделимой транзакцией.
- Если нужные файловые средства/хэширование недоступны, не обещать безопасное восстановление; сообщить блокер.

## Обновление
По поручению сверить новую поставку, сохранить проверенную копию заменяемых файлов. Переносить только инструкции, шаблоны алгоритмов и код модуля. Не заменять CURRENT_STATE, историю, предпочтения, KnowledgeBase и Solutions пустыми шаблонами; знания объединять.
Для обновления Editor-пакета закрыть Unity, сверить installation-record, сохранить пакет и .meta; чужие/изменённые файлы не перезаписывать. Копировать проверенную новую поставку с сохранением прежних .meta, обновить запись установки, затем открыть Unity. При ошибке остановиться и сообщить частичный результат. Сетевой автообновитель не включён.

## Пакеты и удаление
Читать manifest/lock и package.json только нужных зависимостей; уточнять назначение/использование по объектам проекта и записывать PLUGINS.md. Наличие пакета не доказывает использование.
Перед удалением AI Assistant по поручению остановить и удалить наш Editor-пакет, сохранив нужную память. Рабочие assets не удалять. Модуль иначе может создать History снова.
