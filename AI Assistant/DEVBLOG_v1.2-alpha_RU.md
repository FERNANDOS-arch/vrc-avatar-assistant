# Девблог — VRC Avatar Assistant v1.2-alpha

30 сентября 2026. Предыдущая версия: v1.1-alpha. Editor-пакет: 1.2.0-alpha.1.

В v1.1-alpha основой были инструкции Codex и переносимая память. v1.2-alpha добавляет локальный Editor-модуль и инструменты работы с файлами проекта. Выпуск публикуется открыто на GitHub.

## Изменения

1. **История работы в Unity.** Добавлен журнал изменений объектов, свойств, иерархии, сцен и ассетов, включая Undo/Redo. События объединяются, предусмотрены пауза и ротация журнала. Автор указывается как ai/user при явной маркировке; остальные события получают unknown. Полный перехват всех ручных действий не гарантируется.
2. **Установка при первом запуске.** FIRST_RUN поручает Codex установить локальный Editor-пакет, проверить окружение и выполнить проверку запуска. Повторная установка учитывает уже установленный модуль и его локальные изменения. Одно копирование папки без запуска Codex установку не выполняет.
3. **Контрольные точки и восстановление.** CLI сохраняет выбранные файлы и их .meta, проверяет контрольные суммы, показывает план восстановления и блокирует перезапись более новых изменений пользователя. Перед восстановлением создаётся спасательная контрольная точка. Несохранённое состояние Unity не входит в снимок; восстановление выполняется при закрытом Unity.
4. **Проверки по типу задачи.** Добавлены проверки для одежды, предметов, меню и материалов: отсутствующие компоненты, ссылки, материалы и ожидаемые объекты. Результат PARTIAL или FAILED дополняется перечнем проверок SDK, платформы и клиента, которые ещё нужно выполнить.
5. **Совместная работа.** Перед шагом RunAgentStep сверяется состояние целевого аватара и зарегистрированных общих зависимостей. Конфликт блокирует следующий шаг. Есть STOP и восстановление контекста после перезагрузки скриптов. Протокол требует использования API модуля; STOP не отменяет уже выполняющийся код.
6. **Окно помощника.** Tools > VRC Avatar Assistant > Open показывает состояние задачи, последние события, ошибки и конфликты; позволяет управлять журналом, записывать ручные действия и запускать проверки.
7. **Профиль проекта.** Сохраняются версия Unity, платформа, пакеты, выбранный аватар, задача и ограничения. Известные сведения об аватаре и ограничения сохраняются при запуске без выбранного объекта.
8. **Карточки проверенных решений.** Шаблон памяти дополнен условиями применимости, версиями, доказательствами проверки, неудачными попытками и способом восстановления. Задача сначала сверяется с подходящим опытом; неподтверждённые методы не объявляются проверенными.
9. **Учёт плагинов и зависимостей.** CLI собирает manifest, lock-файл и встроенные пакеты. Аннотации назначения, использования аватаром и риска удаления сохраняются при повторном сборе; содержимое этих аннотаций нужно проверять по проекту.
10. **Обновление с сохранением данных.** Инструмент обновления переносит предусмотренные файлы правил и пакета, создаёт резервные копии и сохраняет историю, решения, базу знаний и пользовательские предпочтения. Обновление выполняется из выбранного пользователем комплекта; автоматическая загрузка из сети не добавлена.

## Структура и запуск

Скопируйте AI Assistant в корень проекта Unity и поручите Codex прочитать AI Assistant/AGENTS.md и выполнить FIRST_RUN.txt. Для CLI нужен Python 3.9+. Рабочий Editor-пакет устанавливается в Packages/com.vrc-avatar-assistant.editor, служебные данные — в AI Assistant. Переносимая память остаётся только внутри AI Assistant/AI Memory; отдельный внешний архив памяти не добавляется.

Перед обновлением действующего проекта используйте команду update из MODULE_GUIDE_RU.md и сохраните резервную копию проекта. Перед окончательным удалением служебной папки удалите установленный Editor-пакет, иначе он может создать журнал снова. Unity-мост для управления из Codex подключается отдельно.

## Проверка и ограничения alpha

11 автоматических CLI-тестов прошли. Проверены синтаксис Python и C#, JSON пакета и Editor-only asmdef, состав архива и сохранение пользовательских данных при обновлении. C# проверен синтаксическим анализатором.

Многофайловое обновление не является единой атомарной транзакцией. Облачная синхронизация и обучение весов модели не входят в выпуск; AI Memory хранит инструкции и опыт локально.
